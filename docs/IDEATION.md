# IDEATION.md

## 문제
개인은 할 일을 알아도, 수면 상태에 따라 실제 실행 가능한 계획을 세우지 못해 미루기와 비효율이 발생한다.

## 아이디어
**Sleep2Flow**: 수면시간 + 오늘 할일을 입력하면,
1) 큰 할일 분해
2) 에너지 구간별 배치
3) 낮잠/휴식 포함 실행 계획 자동 생성

## 왜 지금 아이디어인가
- 일반 To-do 앱은 “기록” 중심
- 본 앱은 “실행 가능한 일정 자동화” 중심
- 생산성 향상에 직접 기여

## 후보 비교
1. 일반 할일 체크 앱 → 차별성 낮음  
2. 회의록 요약 앱 → 주제 적합성 중간  
3. 수면연계 생산성 플래너 → **적합성/차별성 높음 (선정)**

## 심사 기준 매핑(요약)
- Agent/Copilot SDK: 계획 생성 에이전트
- 생산성 향상: 계획 수립 시간 단축, 완료율 개선
- Azure: 앱 배포 + 데이터 저장
- 완성도: 입력→생성→결과 E2E
- UX: 2화면, 3클릭 핵심 플로우
- 보안: 최소 데이터 저장, 비밀키 분리

## 리스크
- 시간 부족: 고급 기능 축소
- 모델 응답 지연: 룰 기반 fallback 제공
