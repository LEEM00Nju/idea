# PRD.md

## 1) 제품명
Sleep2Flow (수면 연계 개인 생산성 앱)

## 2) 목표
사용자의 수면 상태를 반영해 “오늘 실제로 실행 가능한 업무 계획”을 자동 생성한다.

## 3) 타겟 사용자
- 개인 일정/업무를 혼자 관리하는 학생/직장인
- 수면 상태에 따라 집중력이 크게 달라지는 사용자

## 4) 핵심 사용자 시나리오
1. 사용자가 오늘 할일 목록과 어젯밤 수면시간 입력
2. 앱이 할일을 분해/우선순위화
3. 시간대별 실행 계획(집중/보조/휴식/낮잠) 제시
4. 사용자가 바로 실행 시작

## 5) MVP 범위

### Must
- 입력 화면(할일, 수면시간)
- 결과 화면(자동 계획표)
- 큰 할일 소단위 분해
- 수면시간 기반 업무 강도 배치
- 실패 시 기본 규칙 결과 출력(fallback)

### Should
- 낮잠 추천 슬롯 제시
- 완료 체크

### Could
- 일일 회고 자동 생성
- 내일 계획 자동 이어쓰기

## 6) 성공 지표
- 계획 수립 시간: 기존 대비 50% 이상 단축
- 계획 시작까지 지연 시간 감소
- 고집중 작업 완료율 증가(데모 기준 자체 측정)

## 7) 비기능 요구
- 응답 시간: 3~5초 내 1차 결과
- 에러 발생 시 사용자 안내 및 기본 계획 제공
